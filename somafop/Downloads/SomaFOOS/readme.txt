Чтобы записать образ CD-диска на CD-диск делайте следующее:
1. Откройте браузер и в адресную строку пишите yuriyprogs.su
2. Программы -> ptinos -> linux -> ваш дистр -> ptinosX.X.xxx (выбирайте версию) (если вашего дистра тут нет то скачайте папку ptinosource и соберите)
3. Откройте программу
4. OC -> SomaFOOS
5. CD: /dev/srX (ваша цифра). Файл: /ваш/путь/cdrom.iso
6. Нажимайте "Форматирование и запись"
