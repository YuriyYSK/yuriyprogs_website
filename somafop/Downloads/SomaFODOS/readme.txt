Чтобы записать образы дискет на дискеты делайте следующее:
1. Откройте браузер и в адресную строку пишите yuriyprogs.su
2. Программы -> ptinos -> linux -> ваш дистр -> ptinosX.X.xxx (выбирайте версию)
3. Откройте программу
4. ОС -> SomaFODOS
5. 1 дискета: /dev/fdX (ваша цифра). Файл: /ваш/путь/disk01.img
   2 дискета: /dev/fdX (ваша цифра). Файл: /ваш/путь/disk02.img
   3 дискета: /dev/fdX (ваша цифра). Файл: /ваш/путь/disk03.img
6. Нажимайте "Форматирование и запись"
